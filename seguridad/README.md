# Repaso de Seguridad Informática · RA1

Web de estudio para el examen de **Seguridad Informática** de 2º CFGM SMR.
Página estática de un solo archivo: no necesita servidor, dependencias ni conexión una vez cargada.

## Qué incluye

- **Temario** — los 7 temas del RA1 resumidos por puntos clave, con las tablas de clase y las trampas de cada tema.
- **Chuleta** — fórmulas, cifras exactas, listas que piden enteras y pares que se confunden.
- **Glosario** — 105 términos buscables.
- **Flashcards** — 125 tarjetas para memorizar definiciones.
- **Simulacro** — con el formato real del examen: 20 preguntas de test (3 puntos), 6 cortas (3 puntos) y 14 casos prácticos (4 puntos). Corrección automática del test y nota final sobre 10.

## Temario cubierto

1. Introducción a la seguridad informática — CIDAN, amenaza, vulnerabilidad y riesgo
2. Tipos de seguridad — políticas, plan de contingencia, auditorías, física/lógica y activa/pasiva
3. Seguridad pasiva — ubicación y protección física de equipos, CPD
4. Listas de control de acceso (ACL) — modelos, POSIX, NTFS y ACL de red
5. Política de contraseñas — ataques, entropía, hash y sal, NIST 2025, MFA
6. Sistemas de alimentación ininterrumpida (SAI) — tipos, dimensionado y autonomía
7. Sistemas biométricos — FAR, FRR, EER, umbral y marco legal

## Uso

Abre `index.html` en cualquier navegador, o visita la página publicada con GitHub Pages.

Tiene control de tamaño de letra (A− / A+) y modo claro/oscuro, y el código de colores está explicado en la propia página: violeta para términos clave, cian para cifras exactas, rojo para prohibiciones y riesgos, verde para lo recomendado y fondo ámbar para definiciones literales.
